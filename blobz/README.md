# Blobz

Co-op party game for 1-5 phones on the same Wi-Fi. Glide around as a blob, collect stuff,
bring it home to the base, carry big crystals together. Team score, 1-3 stars.

- **Play:** https://sluborg.github.io/Game/ (one phone: "Skapa rum", others: type the 4-letter code)
- **Controls:** drag anywhere = glide, 💨 = dash. Desktop: WASD/arrows + space.
- **Quick round:** add `?t=60` to the host's URL for a 60 s round.
- **Dev:** `npm install && npm run dev` (serves on the LAN), `npm test`, `npm run build`.
- **Rules for agents:** [CLAUDE.md](./CLAUDE.md).

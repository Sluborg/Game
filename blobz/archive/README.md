# Blobz archive: retired art (does NOT ship)

Old art that is no longer in the game, kept for reference and history (Stefan 2026-11-14: "archive discarded Claude and
Kenney art"). Files keep their old subpath: `archive/art/<x>` was `public/art/<x>`.

- **Not shipped:** Vite only copies `public/`, so nothing here is in the build or on the Pages site.
- **What is here:** files the game stopped using when it moved to the Ninja Adventure pack (and approved ChatGPT art):
  old Claude-drawn sprites (`scripts/*_art.py`, `fine_art.py`, `fx_sheet.py`, ...), early ChatGPT sheets (goo enemies,
  totems, the first hovering weapons) and anything else the runtime pass showed is never on screen.
- **How it is decided:** `docs/ASSET_INDEX.md` (generated by `scripts/asset_index.py`, runtime column by
  `scripts/asset_runtime.cjs`). A Claude-drawn or Kenney file that is not IN GAME and has no code reference is moved
  here with `git mv` (history kept). Files still referenced by code are listed for Code / Code 2 to unhook first.
- **Licenses:** as listed in `public/assets/LICENSES.md` (own art CC0; ChatGPT art made for this project; Kenney CC0).
- **Bringing one back:** `git mv archive/art/<x> public/art/<x>`, wire it in, re-run the index.

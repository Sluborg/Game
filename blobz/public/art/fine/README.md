# Fine-resolution world sprites

Redrawn with twice the pixels (1 px outline) so they match the blobz' fine pixels (BLOB_SCALE ~1.45 world px per
art px). Same names as the old files, one folder down (`art/fine/<old folder>/<name>`). **Draw at HALF the old
setScale** (e.g. 3 -> 1.5, 2 -> 1, 4 -> 2); strips keep their frame count, frame sizes double.
Generated by `scripts/fine_art.py` (review: `docs/art-review/fine-sheet.png`, old left / fine right).

# Blobz base and base buildings

Own pixel art (CC0), generated by `scripts/base_art.py` (re-run to rebuild; review sheet:
`docs/art-review/base-sheet.png`). Each part has a 1 px plum outline and flat fill + highlight + shade,
same look as `art/props`.

**Scale:** draw everything at **scale 2** (one art pixel = one pixel of the 16 px ground tiles at 2x), integer,
nearest neighbour. **Anchor:** bottom centre (`setOrigin(0.5, 1)`) on the ground point; depth = that y.

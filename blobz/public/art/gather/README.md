# Blobz gathering art

Own pixel art (CC0), generated by `scripts/gather_art.py` (re-run to rebuild; review sheet:
`docs/art-review/gather-sheet.png`, set `BLOB_PNG` to a 36x48 blob render to include the in-hand demo row).
Native size, fine pixels like the blob grid: scale with the blob (`BLOB_SCALE`), nearest neighbour only.
Strips are horizontal: Phaser `this.load.spritesheet(key, url, { frameWidth, frameHeight })`.

## Tools in hand (4-frame swing strips)
| File | Frames | Frame | Pivot |
|---|---|---|---|
| `tool-axe.png` | 4 | 44x48 | (16, 28) |
| `tool-pickaxe.png` | 4 | 44x48 | (16, 28) |
| `tool-rake.png` | 4 | 44x48 | (16, 28) |

- Frames: 0 raised over the head, 1 wind-down, 2 strike (forward), 3 follow-through. Idle/carry: frame 0.
- Placement: put the frame's pivot pixel on blob grid pixel (33, 33) (right side of the body, hand height),
  i.e. draw the frame at blob grid offset (17, 5). Facing left: flip X and use blob pixel (2, 33).
- Draw the tool in front of the blob (higher depth).

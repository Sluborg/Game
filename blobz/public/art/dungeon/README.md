# Blobz test dungeon art

Own pixel art (CC0), generated by `scripts/dungeon_art.py` (re-run to rebuild; review sheet:
`docs/art-review/dungeon-sheet.png`). Weapons use the same rasteriser and pivot convention as
`art/gather` tools; props use the part painter from `art/base`. Nearest neighbour, integer scales.

## Weapons in hand (horizontal strips, 4 frames)
| File | Frame | Pivot | Frames |
|---|---|---|---|
| `weapon-sword.png` | 44x48 | (16, 28) | raised, wind-down, strike, follow-through (swing like the axe) |
| `weapon-hammer.png` | 44x48 | (16, 28) | same swing, heavy head |
| `weapon-spear.png` | 68x48 | (16, 28) | thrust: pulled back, ready, full thrust, recover (fixed angle, slides along the shaft) |

Placement like the gather tools: pivot on blob grid pixel (33, 33), i.e. frame drawn at blob grid offset (17, 5);
facing left: flip X, pivot on (2, 33). Scale with the blob (`BLOB_SCALE`), draw in front of the blob.

## Weapon picker cards
`card-sword.png`, `card-hammer.png`, `card-spear.png`: 48x64 parchment cards, weapon picture + colour ribbon
(red / orange / blue). No text, so the name can be drawn by code if wanted.

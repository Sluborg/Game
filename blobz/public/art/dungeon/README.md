# Blobz test dungeon art

Own pixel art (CC0), generated by `scripts/dungeon_art.py` (re-run to rebuild; review sheet:
`docs/art-review/dungeon-sheet.png`). Weapons use the same rasteriser and pivot convention as
`art/gather` tools; props use the part painter from `art/base`. Nearest neighbour, integer scales.

## Weapons in hand (horizontal strips, 4 frames)
| File | Frame | Pivot | Frames |
|---|---|---|---|
| `weapon-sword.png` | 44x48 | (16, 28) | raised, wind-down, strike, follow-through (swing like the axe) |
| `weapon-hammer.png` | 44x48 | (16, 28) | same swing, heavy head |
| `weapon-spear.png` | 68x48 | (16, 28) | thrust: pulled back, ready, full thrust, recover (fixed angle, slides along the shaft) |

Placement like the gather tools: pivot on blob grid pixel (33, 33), i.e. frame drawn at blob grid offset (17, 5);
facing left: flip X, pivot on (2, 33). Scale with the blob (`BLOB_SCALE`), draw in front of the blob.

## Weapon picker cards
`card-sword.png`, `card-hammer.png`, `card-spear.png`: 48x64 parchment cards, weapon picture + colour ribbon
(red / orange / blue). No text, so the name can be drawn by code if wanted.

## Classes (Präst, Bågskytt, Krigare, Riddare)
**Class hats** are drawn by `src/blob.ts`: `CLASS_HATS = ['Prästluva', 'Fjädermössa', 'Riddarhjälm']` and an optional
`classHat` index on `blobGrid(look, classHat)` / `blobCanvas(look, scale, classHat)`, which replaces the skin hat.
All three are head-shaped hoods, so they fit every body shape. Krigare keeps the skin hat.

**Held gear** (4-frame strips, 44x48, pivot (16, 28), same placement as the weapons):
| File | Frames | Class |
|---|---|---|
| `gear-staff.png` | raised, wind-down, cast forward, follow-through (swing like the sword) | Präst |
| `gear-bow.png` | idle, drawing, full draw with arrow, release (fixed, pointing forward) | Bågskytt |

| `gear-shield.png` | resting low, raising, block (in front), hold (shield moves, never rotates) | Riddare |
| `weapon-sword/hammer/spear.png` | see above | Krigare |

**Class cards** (48x64, same parchment card as the weapon cards, ribbon in the class colour):

## Skill icons (`skills/<class>-<id>.png`, 24x24)

| rogue | rage, knockback, whirlwind, extraheart, lifesteal, power |

Ids were proposed to Code 2; if the dungeon code uses other names, Art renames the files.

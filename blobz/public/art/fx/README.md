# Blobz gameplay effects

Own pixel art (CC0), generated by `scripts/fx_sheet.py` (re-run it to rebuild; preview:
`docs/art-review/fx-sheet.png`). Native size: scale up with nearest neighbour only (`pixelArt: true`).
Animations are horizontal strips: Phaser `this.load.spritesheet(key, url, { frameWidth, frameHeight })`.
